Loyalty Module

Reward outlets and distributors for buying more. Admins set up campaigns. Points are calculated daily. Retailers track them in the FlickPoints app.

Understand
How rewards are calculated
Runs automatically every day after a campaign is saved.
1
Find outlets
The cohort becomes a list of outlets.
2
Check qualifiers
Campaign and program gates, with AND / OR.
3
Measure achievement
The KPI query runs per outlet. Daily campaigns use invoices.
4
Apply slabs
Achievement → slab → FlickPoints. Capping last.
5
Post to the ledger
After the ledger sync days, or once approved.
Understand
Timing
  • Daily calculated each day.
  • Standard Tier month-to-date, recalculated through the month.
  • Grace days keep counting late sales after the end date.
  • Rewards can drop before posting if goods are returned.

Target Cohort
The outlets or distributors a campaign applies to. Built in Cohort 2.0.
  • Use an Outlet or Distributor cohort. User cohorts are not offered.
  • Only active cohorts appear in the campaign.
  • An empty cohort means no rewards. Check it first when a campaign shows nothing.

Self-check quiz
1Which cohort types can a loyalty campaign target?
Outlet or Distributor cohorts, and only active ones. User cohorts are not offered.
2Which slab type can a Tier Bonus program use?
Value Slab only. The slab type is locked and each row picks a tier.
3Where does a Standard Value program's Achievement KPI Query come from?
A KPI Subscription with no target, built on a Global Outlet Metric.
4Ledger sync days must be greater than what?
Grace days, so totals are final before rewards post.
5What happens if the reward type is changed after programs are added?
The programs are cleared, after a confirmation.
6Can capping be set in the program drawer?
No. The program card shows capping, but the drawer has no field for it.
7What end date does a repeatable campaign show in the list?
31 Dec 2999.
8A retailer is at 70, with slabs at 50 and 100. What does Quick Wins say?
"Reach 30 to earn …" followed by the 100 slab's reward value.
Questions retailers ask
QuestionAnswer
"Why don't I see a campaign?"The outlet is not in the campaign's Target Cohort, the campaign has not started, or another company is selected in the switcher.
"My points haven't updated today."Rewards are calculated in a daily run, so today's sales appear after the next run.
"Why can't I redeem?"Redemption in the app is marked Coming Soon.
"It says Qualified, but I got nothing."The Qualified badge currently shows on every campaign. Check the qualifier result in the admin data.
"Quick Wins said I'd earn less than I got."For Multiplier programs, Quick Wins shows the slab value, not achievement × multiplier.
"My joining date is wrong.""Member since" is placeholder text. The real date is Enrollment Date on the Profile screen.

Key notes
  • Cohort first. Only active Outlet or Distributor cohorts.
  • Changing the reward type clears programs.
  • Capping cannot be set in the drawer.
  • Cross Program slabs need a reward KPI link set by the product team.
  • Deduction campaigns cannot be created in the wizard.
  • Cancel in the wizard has no confirmation.
